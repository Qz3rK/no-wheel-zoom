# noWheelZoom

Утилита для Windows: пока активно окно заданной программы (по умолчанию Warcraft III),
колесо мыши не прокручивается, боковые кнопки мыши работают как F1 и F2, а клавиша Win
не сворачивает игру. Нужна тем, кто двигает камеру перетаскиванием средней кнопкой
и случайно меняет зум колесом.

## Поведение

- Глушатся только сообщения колеса — вертикальное и горизонтальное (наклон).
- Средняя кнопка, перетаскивание карты, остальные кнопки мыши не затрагиваются.
- Колесо блокируется только когда целевое окно в фокусе. Свернули игру, переключились
  в браузер — колесо работает как обычно.
- Боковые кнопки мыши отдают F1 и F2: верхняя (передняя) — F1, нижняя (задняя) — F2.
  Работает только когда целевое окно в фокусе, отключается пунктом меню.
  Двойное нажатие даёт двойное F1/F2, поэтому центрирование камеры на герое
  продолжает работать.
- Клавиши Win (левая и правая) не доходят до системы, пока целевое окно в фокусе:
  глушится и нажатие, и отпускание. Побочный эффект — в игре не срабатывают
  и сочетания Win+*, включая Xbox Game Bar. Отключается пунктом меню.
- Значок в трее: левый или правый клик — меню.
  - Pause — временно отключить всю обработку (галочка означает, что пауза включена).
  - Side buttons -> F1 / F2 — маппинг боковых кнопок.
  - Block Win key — блокировка клавиши Win.
  - Exit — выйти.
- Повторный запуск не создаёт вторую копию: программа показывает всплывашку
  у значка и завершается.

## Безопасность

- Ничего не пишет на диск и в реестр, не обращается к сети, не хранит данные.
- Не внедряется в чужие процессы, не читает и не изменяет память игры.
- Эмулирует нажатия клавиш: боковая кнопка отправляет одно нажатие F1 или F2
  через `SendInput`. Это не макрос и не последовательность — одно физическое
  нажатие даёт одно нажатие клавиши, без задержек, повторов и скриптов.
  Такие события система помечает как инжектированные (`LLKHF_INJECTED`).
- Читает только путь к exe активного окна, с минимальным правом
  `PROCESS_QUERY_LIMITED_INFORMATION`.
- Права администратора не требуются.

## Требования

- Windows Vista и новее; проверено на Windows 10/11. Архитектуры x86, x64, ARM64.
- Готовому exe ничего не нужно: статическая линковка, из внешних зависимостей только
  системные DLL.

## Сборка

В репозитории должны лежать `version.rc`, `noWheelZoom.manifest` и `noWheelZoom.ico`:
ресурсы компилируются в exe, без файла иконки сборка падает.

### MinGW-w64
1. Открыть шелл MinGW64 (MSYS2) или распаковать winlibs и добавить его bin в PATH.
2. Запустить `build.bat`.
3. На выходе `noWheelZoom.exe`, около 45-60 КБ (из них иконка — примерно 25 КБ).

Вручную:
```
windres version.rc -O coff -o version.o
gcc -Os -s -mwindows -static -static-libgcc -ffunction-sections -fdata-sections -Wl,--gc-sections -o noWheelZoom.exe noWheelZoom.c version.o -luser32 -lshell32
```

### MSVC (Visual Studio 2022)
1. Открыть «x64 Native Tools Command Prompt for VS 2022».
2. Запустить `build-msvc.bat`.
3. На выходе `noWheelZoom.exe`, около 85-115 КБ.

Вручную:
```
rc /nologo version.rc
cl /nologo /O1 /MT /DNDEBUG noWheelZoom.c version.res user32.lib shell32.lib
```

## Использование

```
noWheelZoom.exe
noWheelZoom.exe -target war3.exe
noWheelZoom.exe -target="EscapeFromTarkov.exe"
```

- Без аргументов блокируется `warcraft iii.exe`. Для старой классики (1.27) укажите `-target war3.exe`.
- `-target` принимает имя файла процесса; путь тоже можно, берётся последний компонент.
- Один экземпляр обслуживает одну игру. Для нескольких игр сразу запускать несколько
  копий бессмысленно: вторая копия завершится.
- Маппинг боковых кнопок и блокировка Win включены по умолчанию, переключаются галочками
  в меню значка. Настройки не сохраняются между запусками.

Автозапуск: ярлык в папке `shell:startup` либо задача в Планировщике заданий
с параметром «Перезапускать при сбое» (если хук когда-нибудь снимет система).

## Известные ограничения

- Колесо, боковые кнопки и клавиша Win обрабатываются во всём окне игры, включая
  меню, настройки и чат. В чате Win тоже не сработает.
- Если фокус забирает оверлей (Xbox Game Bar, Steam в отдельном окне), на этот момент
  колесо проходит в игру.
- Windows может снять низкоуровневый хук, если процесс надолго замер (отладчик, дамп).
  Внешне это выглядит как «перестало работать» — помогает перезапуск.
- Win+L заблокировать нельзя: эта комбинация обрабатывается ниже пользовательских
  хуков. Ctrl+Esc по-прежнему открывает «Пуск».
- Если игра запущена от администратора, запускайте утилиту тоже от администратора.
  Иначе ни блокировка Win, ни F1/F2 не сработают: система не пропускает ввод
  между процессами разного уровня целостности.
- Интерфейс (меню трея, всплывашка) на английском; чтобы перевести, замените строки
  в `noWheelZoom.c`, сохраните файл в UTF-8 с BOM и собирайте MSVC с ключом `/utf-8`.

## Внимание: мультиплеер

Программа не автоматизирует игру и не читает её память: одно нажатие кнопки даёт
одно нажатие клавиши, без последовательностей, задержек и повторов. Тем не менее она
устанавливает глобальные хуки мыши и клавиатуры и генерирует события клавиатуры через
SendInput, которые система помечает как инжектированные. Античиты и правила игровых
сервисов могут относиться к такому вводу настороженно. Решение об использовании
в сетевых матчах — на вашей ответственности.
